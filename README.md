# 基于区块链的数字病例存证系统

基于区块链智能合约的医疗病历存证和医保发票验证系统。

## 功能特性

### 用户角色

#### 👨‍⚕️ 医生
- ✅ 创建病历记录（诊断、治疗方案、处方）
- ✅ 为病人开具发票
- ✅ 查看自己创建的所有病历
- ✅ 数据统计（总病历数、今日病历数）
- ✅ 病历和发票数据上链存证

#### 👤 病人
- ✅ 查看自己的所有病历记录
- ✅ 查看所有发票信息
- ✅ 查看发票验证状态
- ✅ 数据统计（总病历数、总发票数、已验证发票数、总金额）
- ✅ 查看关联的病历详情

#### 🏢 发票查证单位
- ✅ 查看所有待验证发票
- ✅ 验证发票（通过/拒绝）
- ✅ 查看已验证发票历史
- ✅ 查看发票关联的病历信息
- ✅ 数据统计（总发票数、待验证数、已验证数）
- ✅ 搜索发票功能

### 核心功能
- 🔐 用户注册和登录（基于MetaMask钱包）
- 📝 病历上链存证（不可篡改）
- 🧾 发票上链验证（防伪验证）
- 🔒 数据隐私保护（仅授权用户可查看）
- 📊 实时数据统计和仪表板
- 🔔 友好的通知提示系统
- 🎨 简洁美观的现代化UI设计
- 🔍 搜索和筛选功能

## 技术栈

- **前端**：React + TypeScript + Tailwind CSS
- **区块链**：Hardhat + Solidity
- **Web3**：ethers.js

## 使用说明

### 环境要求
- Node.js >= 16.0.0
- MetaMask 浏览器扩展

### 快速开始

1. **安装依赖**
   ```bash
   npm install
   ```

2. **启动本地区块链节点**
   ```bash
   npm run node
   ```
   这会启动 Hardhat 本地网络，默认运行在 `http://localhost:8545`
   终端会显示账户地址和私钥，将其导入metamask作为用户

3. **部署智能合约**（新终端窗口）
   ```bash
   npm run compile
   npm run deploy
   ```
   部署成功后，会显示合约地址，请将其复制到 `.env` 文件：
   ```
   VITE_CONTRACT_ADDRESS=你的合约地址
   ```

4. **启动前端应用**（新终端窗口）
   ```bash
   npm run dev
   ```

5. **配置 MetaMask**
   - 打开 MetaMask 扩展
   - 添加网络：
     - 网络名称：Hardhat Local
     - RPC URL：http://localhost:8545
     - 链ID：31337(可能是1337)
     - 货币符号：ETH
   - 导入测试账户（Hardhat 会显示账户私钥）

6. **使用系统**
   - 访问 http://localhost:3000
   前端启动后会自行跳转到系统
   - 点击"连接 MetaMask 钱包"
   - 如果未注册，点击"立即注册"并选择角色
   - 开始使用系统功能

### 使用流程示例

#### 医生创建病历
1. 登录系统（医生角色）
2. 点击"创建病历"
3. 输入病人钱包地址
4. 填写诊断、治疗方案、处方信息
5. 提交后数据自动上链

#### 医生开具发票
1. 在医生工作台点击"开具发票"
2. 选择病人地址和关联的病历ID
3. 输入金额和发票编号
4. 提交后发票上链

#### 病人查看信息
1. 登录系统（病人角色）
2. 在"我的病历"标签页查看所有病历
3. 在"我的发票"标签页查看所有发票
4. 点击"查看详情"查看完整信息

#### 查证单位验证发票
1. 登录系统（查证单位角色）
2. 在"待验证"标签页查看待验证发票
3. 点击"查看详情"查看发票和关联病历
4. 点击"通过"或"拒绝"进行验证
5. 验证结果上链保存

## 技术亮点

- **区块链存证**：所有病历和发票数据永久存储在区块链上，不可篡改
- **权限控制**：基于角色的访问控制，确保数据隐私
- **实时更新**：使用事件监听和状态管理，实时反映链上数据变化
- **用户体验**：现代化的UI设计，流畅的交互体验
- **错误处理**：完善的错误提示和异常处理机制

## 注意事项

1. 本系统为演示项目，实际生产环境需要：
   - 更完善的权限验证机制
   - 更安全的哈希算法（建议使用 SHA-256）
   - 数据加密存储
   - 审计日志功能

2. 测试环境使用 Hardhat 本地网络，生产环境需要部署到真实区块链网络（如以太坊主网、Polygon等）

3. 确保 MetaMask 连接到正确的网络，否则无法正常使用
